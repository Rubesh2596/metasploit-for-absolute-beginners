# Glossary

## Beginner-friendly terms

### IP address
A unique address assigned to a device so it can be identified on a network.

### Port
A numbered communication endpoint used to distinguish services on the same device.

### Protocol
A set of rules that defines how information is exchanged between devices.

### Service
A program or process that listens for requests, such as a web service or SSH service.

### Host
A device connected to a network, such as a computer, router, or server.

### Target
The system or service being tested in a lab or authorized environment.

### Vulnerability
A weakness in software, configuration, or design that could be misused under the right conditions.

### Exploit
The method or code used to trigger a vulnerability.

### Payload
The code that runs after a trigger or successful interaction.

### Module
A reusable component in Metasploit that performs a specific task or security function.

### Auxiliary
A Metasploit module type used for scanning, enumeration, or information gathering.

### Session
An active connection or managed interaction created in the Metasploit environment.

### Shell
A command environment that lets a user interact with a system through commands.

### Reverse connection
A connection where the target connects back to the attacker or local system.

### Local host
The machine you are currently using or the local interface involved in the connection.

### Remote host
The destination or target system being communicated with.

### Penetration testing
A controlled way to evaluate system security within a defined, authorized scope.

### Virtual machine
A simulated computer that runs inside another machine.

### Host-only network
A private network used to isolate lab machines from the real internet.
